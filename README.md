# Matching Emojis 

## Опис
Matching Emojis — це веб-гра на запам’ятовування, створена за допомогою React та Vite.
Гравець відкриває картки та знаходить пари однакових емодзі.

## Технології
- React
- Vite
- React Hook Form
- Yup

## Встановлення

npm install

## Запуск у режимі розробки

npm run dev

## Збірка проєкту

npm run build

## Перегляд production-версії

npm run preview

## Лінтинг

npm run lint
