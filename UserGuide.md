# User Guide & Privacy Policy

## 1. Project Description
Matching Emojis Game is a browser-based memory game where players flip cards to find matching emoji pairs. The game includes multiple levels with increasing difficulty.


## 2. How to Use

1. Open the application in your browser.
2. Choose a level.
3. Click on cards to reveal emojis.
4. Match pairs to complete the level.
5. View your moves and time.
6. Restart or return to the main menu anytime.

Game progress and preferences may be stored locally in the browser.


## 3. Levels

- Level 1 – 3x2 grid
- Level 2 – 4x3 grid
- Level 3 – 6x4 grid
- Level 4 – 6x5 grid
- Level 5 – 8x6 grid
